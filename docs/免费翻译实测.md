OPUS：出现公司名错误、“减少40%”变成“使用40%”，不采用。
NLLB：500 billion 误译为500亿美元，并遗漏句子内容，不采用。
MyMemory：六次 responseStatus=200、quotaFinished=false；金额与百分比方向正确。Token 被译为“代币”等专业词，需术语恢复规则，再提供中文说明。

OPUS 单句耗时：0.433, 0.339, 0.441, 0.289, 0.232, 0.358 秒。
NLLB 单句耗时：3.322, 2.859, 3.623, 2.917, 2.071, 2.545 秒。

NLLB 两个量化权重合计894,626,254 bytes，约895 MB，下载过程中多次超时，最终使用分段断点续传并核对官方SHA256成功。所有模型及缓存已放在D:\Chat GPT下，没有上传到GitHub。

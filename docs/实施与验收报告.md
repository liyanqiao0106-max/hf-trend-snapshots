# AI 产业看板：Windows 实施与验收报告

实施日期：2026-10-05

本地项目：`D:\Chat GPT\AI产业看板`

线上项目：<https://liyanqiao0106-max.github.io/hf-trend-snapshots/>

## 最终架构

项目保留 GitHub Actions + GitHub Pages，无需增加在线数据库。Python 适配器分别抓取来源并输出统一 JSON；校验成功后，最新数据发布到 Pages，历史数据压缩到按月 Release。前端只按需读取当前栏目 JSON。电脑关机不会影响线上访问和定时采集。

每日任务在上海时间 12:00 运行，采集新闻、模型价格、GPU 云报价与存储价格。每周二 12:20 汇总 OpenRouter Token、Hugging Face 和 GitHub 项目。所有任务使用公开仓库的标准免费 runner，周末照常；GitHub 排队可能导致实际完成时间晚于 12:00。

## 本轮升级

- 将七栏前端扩展为八栏：总览、产业新闻、Token 自然周、模型 API 价格、GPU 云报价、存储硬件价格、Hugging Face、GitHub AI 项目。
- 新闻加入官方来源优先、事件词筛选、URL 规范化、标题聚类去重和中英文数量控制。
- Token 用量按 UTC 自然周生成完整周、进行中周与预览周，并合并长尾为 Others。
- 模型价格保留缺失值，分列输入、输出、缓存读写价格、上下文和输入输出模态。
- GPU 价格分开保存实例总价与每 GPU 时价；Azure 为默认免费来源，RunPod、Vast.ai 通过可选 Secret 接入。
- Hugging Face 与 GitHub 改为周度定稿；GitHub 增加官方仓库、topic 搜索和最新 Release 信息。
- 全部数据使用 schema v2，记录来源、状态、错误和口径；任一来源失败不会破坏其他模块。
- 页面采用延迟加载与请求缓存；桌面和手机宽度均有自动化浏览器测试。

## 存储硬件价格

该栏目不包含新闻，数据行必须带价格、单位、报价类型、来源和历史序列。

| 数据 | 免费来源 | 处理方式 |
|---|---|---|
| DDR4/DDR5 芯片与模组 | DRAMeXchange 当日公开表格 | 保存 session average，并从每日快照计算相对前次变化 |
| SLC/MLC NAND、TLC NAND Wafer | DRAMeXchange 当日公开表格 | 保存平均价格和原始报价单位 |
| GDDR5/GDDR6 | DRAMeXchange 当日公开表格 | 保存当前公开品种；GDDR4 无活跃公开报价时留空 |
| SSD | DRAMeXchange SSD Street Price | 保存平均价，并根据容量计算 USD/TB |
| 存储设备整体趋势 | BLS/FRED `PCU3341123341121` | 月度 PPI，计算 MoM 与 YoY；这是指数，不是现货价 |
| HBM | GPU 云价格与显存容量 | 计算 USD/HBM-GB·小时代理；明确包含 GPU 计算、CPU、RAM 和平台成本 |

DRAMeXchange 只提供当前公开页面，没有免费历史 API。项目不会抓取会员历史数据，而是从上线日开始每天积累自己的 90 天序列。实现参考开源项目 `wongcingshen/AI_hardware_tracker` 的公开页面处理思路，解析、契约和前端均由本项目独立实现。

## 翻译与密钥

国际新闻使用 MyMemory 匿名免费接口。系统在滚动 24 小时内最多提交 3000 字符，缓存命中不重复扣量；失败请求计入预算，额度耗尽或翻译失败时保留英文并标明状态，不使用收费服务。

OpenRouter 零充值账户已完成只读 API 验证。密钥只存在本地 `.env` 与 GitHub Secret `OPENROUTER_API_KEY`，不会写入 HTML、JSON、Release、日志或迁移包。RunPod、Vast.ai 未配置时显示 `not_configured`，不会令整个 GPU 模块失败。

## 存储规模

完整实测压缩快照约 1.60 MB，保留 90 天约 145 MB。实际大小随 Hugging Face 行数和新闻数量变化，每次运行会生成 `storage-report.json`。Pages 只放最新快照；Pages artifact 保留 1 天；持久历史保存在 Release 附件，不占 Actions 的 500 MB artifact 配额。

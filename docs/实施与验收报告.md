# AI 产业看板：实施与验收报告

本地项目：`D:\Chat GPT\AI产业看板`。本轮为本地开发和真实抓取验证，尚未向 GitHub 推送、修改线上页面或创建云端收费资源。以下结论优先于此前初步调查中的候选方案。

## 已确认并实现

个人中文 HTML 看板，沿用现有公开网址和 GitHub Actions + Pages。上海时间每天中午 12:00 触发，周末照常；打开页面读取最近一次成功采集。GitHub 定时任务可能延迟，上午通常是前一天的数据，下午在任务成功部署后才更新。

独立采集模块 → 标准 JSON → 持久压缩快照 → HTML 展示。未增加在线数据库。失败模块保留旧值并显示状态；其他成功模块继续更新。专业词保留英文并提供中文说明。

## 储存额度与实测体积

| 储存方式 | 官方额度或限制 | 本项目用途 |
|---|---|---|
| Actions artifact | GitHub Free 500 MB，与 GitHub Packages 共用；不是每天重置 | 临时 Pages 部署包，保留一天 |
| Actions cache | 每仓库免费 10 GB，与 artifact 分开 | 本版不缓存翻译模型，避免持久缓存膨胀 |
| Release 附件 | 每文件小于 2 GiB，每 Release 最多 1000 附件；官方未列总大小或带宽上限 | 持久每日快照，用户已确认保留 90 天 |
| GitHub Pages | 发布站点不超过 1 GB；带宽软限制每月 100 GB | 仅前端与最近成功 JSON，不放全部历史 |

公开仓库的标准 GitHub-hosted runner 免费；不选择收费的 larger runner，不增加收费服务。账号级 artifact 用量也可能来自其他仓库；上线前应核对账号免费额度及禁止超额付费的设置。

**首次采集实际体积**：HF CSV gzip 1,446,583 bytes；全部已接入模块的 Release 日压缩包 **1,598,023 bytes**，约 **1.60 MB / 1.52 MiB**；包内未压缩文件合计 2,185,256 bytes。

接入国际新闻译文和翻译缓存后的最新快照为**1,606,108 bytes，约1.61 MB / 1.53 MiB**，保留90天约145 MB。尚不含待验证OpenRouter用量，不能视为最终上限。每天生成 `storage-report.json` 报告真实体积。模型权重、环境依赖、API key和全文文章均不进入日快照。

官方依据：[Actions 计费与额度](https://docs.github.com/en/billing/concepts/product-billing/github-actions)、[Release 额度](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)、[Pages 限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)、[schedule 延迟及停用说明](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)。

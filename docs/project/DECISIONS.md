## D-010：GitHub 全站趋势榜与增量标红口径

- 日期：2026-10-29
- 用户决策：侧栏保留一个“GitHub”入口；GitHub 页“数据与图表”工具栏在搜索框左侧设置“趋势榜 / AI 项目”切换，趋势榜在左并作为默认视图。趋势榜展示 GitHub 全站 Trending 原榜单（含非 AI 项目），AI 项目沿用现有规则筛选。每日一次抓取今日、本周、本月三个榜单，并在页面统一标注采集时间。
- 字段：趋势榜显示原站排名、项目名称、总 Stars、所选周期新增 Stars、原文简介；原站无简介时明确标注。新增 Stars 取该周期 GitHub 页面给出的数值，不以相邻快照差值代替。
- 视觉口径：趋势榜当期新增 Stars、AI 项目 Stars 净变化、Hugging Face 下载加速度，仅正值中的前 20% 使用红字；Hugging Face 本期下载不标红。判定基于各自完整榜单，筛选不改变阈值。
- 来源限制：GitHub 提供今日、本周、本月窗口，但未公布固定刷新时间；以每日快照为观察频率，并保留实际采集时间。

## D-008：X 账号动态正式接入但仅本机采集

- 日期：2026-10-10
- 决策：将用户提供的 50 个 AI 产业 X 账号作为唯一正式清单，接入主看板侧边栏“X 账号动态”；不再以独立 HTML 作为产品入口。清单的名称、Handle、分组、关注重点和 15 个优先账号统一保存在 `config/x_watchlist.json`。
- 运行边界：展示使用主看板静态 JSON；刷新通过本机 `bash scripts/run-local.sh collect-x`，复用已获用户授权的主 Chrome/X 登录态，并排除回复与原生转帖，避免高频回复账号挤占分组额度。GitHub Actions 不采集 X，也不保存 Cookie、会话或凭据；发布到 Pages 前需由本机产生新快照并进入既有发布流程。
- 原因：X 搜索需要真实浏览器登录态，无法在无交互 Actions 中可靠、安全地运行；本地采集与静态展示分离，可以把账号管理和阅读体验纳入主项目，同时保持凭据只在用户电脑中。
